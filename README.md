# صِلة (Sila) — قناة التوزيع الرسمية

هذا المستودع **عام** مخصص حصرياً لتوزيع تحديثات تطبيق أندرويد «صِلة»:

- ملفات APK الجاهزة للتثبيت
- ملاحظات الإصدار (Release Notes) لكل إصدار

وظيفته تمكين ميزة **التحديث الداخلي (In-App Updates)** داخل التطبيق:
يفحص التطبيق `releases/latest` هنا دورياً ويعرض التحديث للمستخدم
(مرن أو إلزامي)، كما يُقرأ منها وضع الصيانة عند تفعيله.

الكود المصدري للتطبيق محفوظ في مستودع خاص منفصل.

## علامات التحكم في متن الإصدار (يستخدمها المشرف)

| العلامة | المعنى |
|---------|--------|
| `[مطلوب]` | تحديث **إلزامي** — التطبيق لا يعمل حتى يُحدَّث |
| `[صيانة]` | تشغيل **وضع الصيانة** — شاشة صيانة + زر نسخة احتياطية |
| `[صيانة: نص]` | وضع الصيانة مع رسالة مخصصة تظهر للمستخدم |
